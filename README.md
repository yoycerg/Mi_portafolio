# Portafolio de Yoycer García

Portafolio estático creado con HTML, CSS y JavaScript, sin frameworks ni dependencias.

## Archivos
- `index.html`: contenido y estructura.
- `style.css`: diseño y adaptación a diferentes pantallas.
- `script.js`: menú móvil, filtros y animaciones al desplazarse.

## Probar en tu computador
1. Descarga y descomprime el proyecto.
2. Abre la carpeta en Visual Studio Code.
3. Abre `index.html` en tu navegador. También puedes usar la extensión Live Server si ya la tienes instalada.

## Antes de publicar
- Reemplaza los enlaces de ejemplo de GitHub y LinkedIn por tus perfiles reales.
- Cambia los enlaces de cada tarjeta por los repositorios correspondientes.
- Agrega un video real en la sección Video.
- Revisa que las descripciones reflejen con precisión lo que hiciste en cada proyecto.

## Publicar en GitHub Pages
1. En GitHub, crea un repositorio nuevo y exclusivo, por ejemplo `mi-portafolio`.
2. Sube `index.html`, `style.css`, `script.js` y `README.md` a la raíz del repositorio.
3. En el repositorio, entra en **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/(root)`, y pulsa **Save**.
6. Espera a que termine la publicación. GitHub mostrará la dirección pública en la sección Pages.

El sitio puede tardar unos minutos en aparecer. Si haces cambios, súbelos al mismo repositorio para actualizarlo.
