# Portafolio de Yoycer García

Portafolio personal estático creado con HTML, CSS y JavaScript.

## Archivos
- `index.html`: contenido y estructura del sitio.
- `style.css`: diseño adaptable, estilos, animaciones y tema claro/oscuro.
- `script.js`: filtros y búsqueda de proyectos, ventanas de detalles, menú móvil y acciones interactivas.

## Cómo abrirlo
Abre `index.html` en un navegador. Para probarlo localmente también puedes usar la extensión Live Server de Visual Studio Code.

## Publicar con GitHub Pages
1. Sube estos archivos a la raíz de un repositorio público de GitHub.
2. Abre **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/(root)`.
5. Guarda y espera a que GitHub Pages publique la página.

## Selector de idioma
El botón **EN** del menú cambia la interfaz y los detalles de proyectos al inglés; el botón **ES** vuelve al español.
